# Гараж — тюнинг Лады Гранты

Telegram Mini App: подбор тюнинг-деталей под конкретную модификацию Гранты,
структурированные отзывы про посадку, гараж с учётом вложений и респекты.

Документы проекта лежат уровнем выше:
[бриф](../GRANTA_TUNING_PRODUCT_BRIEF.md) · [ресерч](../GRANTA_TUNING_RESEARCH.md) · [LATER](LATER.md)

## Архитектура

Next.js: экраны и API-роуты в одном проекте. Хостинг — Vercel (статический экспорт снят,
GitHub Pages больше не используется).

**База.** Один слой данных на две среды (`src/server/db.ts`): на проде Neon (Postgres по HTTP,
дружит с serverless), локально PGlite — тот же Postgres, собранный в WASM, без отдельного сервера.
SQL один и тот же, локальная разработка не расходится с продом. Файл базы — в `.data/`.

**Авторизация.** Каждый запрос несёт `initData` Telegram в заголовке, сервер проверяет подпись
HMAC заново (`src/server/telegram.ts`). Без этого любой мог бы прислать чужой `user_id`
и писать в чужой гараж. Локально Telegram нет, поэтому при `ALLOW_DEV_USER=1` пускается
фиктивный пользователь — на проде эта переменная не ставится.

**Пуш через две недели.** `/api/cron/ask` находит установки старше 14 дней без отзыва,
отправляет одно сообщение и помечает `asked_at`, чтобы не долбить повторно.
Расписание — в `vercel.json`, раз в сутки.

## Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | локально и на проде | проверка подписи initData, отправка пушей |
| `DATABASE_URL` | прод (и в .env.local от Vercel) | Neon Postgres. Локально **не используется**: PGlite включается всегда, кроме `NODE_ENV=production` или явного `USE_REMOTE_DB=1` — чтобы разработка не писала в боевую базу |
| `CRON_SECRET` | только прод | защищает `/api/cron/ask` от посторонних вызовов |
| `ALLOW_DEV_USER` | только локально | фиктивный пользователь вместо Telegram |

## Где мы в конвейере

Фаза 3 — живой UI. Дизайн-система снята с design30.club один в один (токены, радиусы,
движение, устройство компонентов), компоненты со состояниями в Storybook, экраны собраны
из библиотеки. Правила и опорные значения — в `AGENTS.md`.

## Запуск

```bash
npm run dev
```

Дев-сервер — порт 3200, витрина компонентов — `npm run storybook` на порту 6007
(конфигурации `granta` и `granta-storybook` в `.claude/launch.json`).
Карта экранов и happy path — на `/flow` и в стори `Product/Карта экранов`.

## Что уже проверено вживую

- Выбор кузова → модификации → лента → карточка детали → добавление → профиль с гаражом → сборка
- Фитмент считается от модификации: паук 4-2-1 на 8-клапанном показывает «не подходит»
- Лента фильтруется по кузову: на универсале видно пустое состояние, а не чужие седаны
- Сумма вложений считается из обязательного числового поля цены
- 360px без горизонтального скролла, тап-зоны 44px, статический экспорт собирается
